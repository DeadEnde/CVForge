Features

Built to forge fast

Everything you need to go from a boring PDF to a portfolio that lands interviews.

🧠‍💻

Smart parsing

Extracts name, contacts, skills, experience, projects & education — and detects your domain automatically to pick the right theme.

🎨

11 domain themes

Neon Code for developers, Studio Rose for designers, Golden Hour for photographers, Fintech, Scholar, Executive & more.

🌍

Arabic RTL

language=ar generates a fully direction-aware page: lang="ar" dir="rtl", right-aligned, Arabic-ready.

📄

PDF · DOCX · MD · TXT

Upload any CV file — pypdf and python-docx extract the text server-side, no formatting work needed.

🔒

Private & self-hosted

Nope, yer CV is your data: run CVForge locally as an MCP server — or use the free hosted demo. No tracking, no storage.

⚡

MCP + API + offline

Ship it as a model tool (MCP), via the REST API, or as one self-contained HTML file that runs entirely in the browser.
